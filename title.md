A Dual-Tier Smartphone-to-LoRa Transceiver Relay Framework for OAline Disaster Communication

Under catastrophic disaster circumstances where cellular communications networks, power grid infrastructures and Internet backbone communications collapse, localized communication becomes an essential aspect that determines public safety and survival. Modern-day mobile operating systems limit long-range peer-to-peer ad-hoc communication networks because of the background power management mechanisms and hardware constraints. This study introduces a lowcost emergency communication system based on an oA-grid infrastructure that allows establishing a connection between smartphone users through long-range sub-GHz radios. We use BLE as the technology that enables smartphone connection with ESP32 LoRa modules that create a one-hop point-to-point sub-GHz communication link for sending vital text messages over several kilometers distance, without utilizing cellular communications.
